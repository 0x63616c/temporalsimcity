# TemporalSimCity

An explorable 3D city that shows how Temporal actually works. Inspired by
[PGSimCity](https://github.com/NikolayS/PGSimCity).

Design is being charted with `/wayfinder`. The map is
[TemporalSimCity — the map](https://github.com/0x63616c/temporalsimcity/issues/1) — read it
before starting work; it holds the destination, the standing rules for this effort, and the
decisions made so far.
